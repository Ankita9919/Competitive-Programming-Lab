* Q1 - 2D Array Row Major Address
* Q7 - 1D Array Effective Address
* Q8 - 2D Array Column Major Address
* Q9 - Array Insertion and Deletion

### 02. Tree

* Q2 - Tree Height
* Q3 - Number of Nodes
* Q4 - Internal Nodes
* Q5 - Leaf Nodes

### 03. Searching

* Q6 - Binary Search
* Q21 - Student Name Search

### 04. Graph

* Q10 - Adjacency Matrix and List
* Q11 - Breadth First Search (BFS)
* Q12 - Depth First Search (DFS)

### 05. Graph Algorithms

* Q13 - Prim's Algorithm
* Q14 - Kruskal's Algorithm

* Q16 - Dijkstra's Algorithm
* Q17 - Bellman-Ford Algorithm

### 06. Basic Programs

* Q18 - Fibonacci Series

### 07. Applications

* Q19 - University Attendance Analysis
* Q20 - Hospital Emergency Monitoring
* Q22 - Library Book Code Validator
